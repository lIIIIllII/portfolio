SAFE-ORCH

여러 업체가 같은 구역과 장비를 나눠 쓰는 현장에서 작업 일정이 부딪히면, AI 에이전트가 해결안을 만들고 사람은 그중 하나를 골라 승인합니다. 데모 현장은 조선소 원·하청 혼재작업입니다.

주요 기능

  • 일정 넣기 · 새 일정이 들어오면 기존 일정과의 충돌을 묶어 검토하고, 세 방향의 해결안을 나란히 비교
  • 자연어 요청 · 문장으로 작업을 요청하면 에이전트가 작업 값을 해석해 생성. 스스로 정한 값은 카드에 표시되어 바로 수정 가능
  • 지연 신고 · 신고 즉시 승인을 잠그고, 어떤 작업이 얼마나 밀리는지 분석해 사실 수정안을 제시
  • 협의와 승인 · 담당자별 변경 요청, 항목별 수락과 이견, 감독자의 최종 승인과 확정 통지

AI 활용

  • 멀티 에이전트 구조 · 메인 에이전트가 상황을 보고 작업 접수, 일정 검토, 재계획, 협의, 신고 대응 5개 전문 에이전트를 호출
  • 병렬 재계획 · 재계획 에이전트 3개를 기존 위주, 추가 위주, 적절하게 세 방향으로 동시에 실행. 같은 결과는 하나로 합쳐 표시
  • 이견 반영 · 담당자가 남긴 이견 사유를 시간·자원 조건으로 바꿔 다시 계획
  • 근거의 분리 · 변경 작업 수 같은 숫자는 서버가 계산하고, 에이전트의 글은 의견으로 따로 보여 판단 근거를 투명하게 유지

FinShield

송금하는 순간 AI가 거래의 위험도를 분석하고, 위험한 거래는 경고하거나 보호자 승인을 거치게 해 금융 취약계층의 사기 피해를 막는 서비스입니다.

주요 기능

  • 위험도 기반 송금 · 송금 확인 단계에서 AI 위험도를 보여주고, 위험 수준에 따라 경고 또는 보호자 승인으로 처리
  • 보호자 승인 · 위험 거래는 보호자가 승인해야 실행되고, 거절되면 잔액 변동 없이 차단
  • 재송금 차단과 냉각 기간 · 승인 대기 중인 거래가 있으면 추가 송금을 막아 연속 피해를 방지
  • 참여형 블랙리스트 · 같은 계좌에 신고가 5건 쌓이면 자동으로 블랙리스트 등록

AI 활용

  • 하이브리드 위험 점수 · XGBoost 이상거래 탐지 모델과 리스크 모델의 결과를 결합해 최종 위험도 산출
  • 개인 행동 기준선 · 사용자별 평소 거래 패턴을 저장해 두고, 평소와 다른 거래를 따로 감지
  • 설명 가능한 AI · SHAP으로 위험 판단의 근거를 뽑아 사용자가 이해할 수 있는 한국어 설명으로 변환
  • 모델 선택의 이유 · 밀리초 단위 추론 속도, 판단 근거 해석, 정형 데이터 적합성을 기준으로 딥러닝 대신 XGBoost 선택. 금융 데이터 보안을 위해 외부 LLM API는 사용하지 않음
